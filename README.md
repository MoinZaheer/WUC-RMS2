Instructions to Run the RMS:

1. Download and extract the the WUC-RMS Zip file
2. Copy the php-8.7 folder to C drive (C\:php)
3. Search "edit environment variables for your account" in windows
4. Select "Path" and click "Edit"
5. Click "New" and paste the path to the php folder e.g(C\:php)
6. Rename the path accordingly if needed
7. Click "Ok" and "Ok" again
8. Open the the WUC RMS folder in file explorer
9. Open the Public Folder
10. Right Click and Open Terminal (while in the public folder)
11. Run the Command: php -S localhost:8000
12. In the web-browser Search for http://localhost:8000
